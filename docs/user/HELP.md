# Quick Help

## Quick Start

1. Selecciona el archivo base exportado desde PFCG.
2. Selecciona `RULES.xlsx`.
3. Selecciona la carpeta de salida.
4. Ejecuta **Validar**.
5. Revisa:
   - Advertencias
   - Cobertura
   - Cambios
6. Si no hay errores `SEV1/SEV2`, ejecuta **Procesar**.

## Atajos

- `F1`: ayuda
- `F5`: validar
- `F6`: procesar
- `Esc`: cancelar

## Outputs

- `<base>_MOD`
- `<base>_MOD_LOG.csv`
- opcional `<base>_MOD_META.json`
